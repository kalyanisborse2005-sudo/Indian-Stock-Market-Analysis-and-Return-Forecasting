# Indian Stock Market Analysis and Return Forecasting

## Project Overview

This machine-learning project analyzes historical daily stock data for Indian companies from 2000 to June 2020. It processes many company CSV files, calculates annual stock returns and daily market breadth, and evaluates a Ridge regression model that forecasts returns over the next 20 trading sessions.

The project uses Python for data processing and machine learning, then saves its results in an Excel workbook.

## Project Objectives

- Process stock data stored in separate company CSV files.
- Study annual stock returns and identify market ups and downs.
- Calculate market breadth, or the daily share of available stocks that increased in price.
- Build a Ridge regression model to estimate future returns.
- Compare the model with a simple zero-return prediction baseline.
- Save the analysis results in an Excel workbook.

## Dataset

The dataset is from Kaggle:

[Indian Stock Data](https://www.kaggle.com/datasets/sagara9595/stock-data)

The dataset contains historical price and trading information for Indian companies. The files are supplied separately as CSV files. The dataset used in this project covers 2000 through June 2020.

Analysis Method
Data processing
The program reads the company CSV files, checks and standardizes date and price data, sorts records by date, and calculates returns using adjusted closing prices when available.
Annual returns
For each company file and year with enough data, the program calculates the stock-file return based on available adjusted closing prices. It then summarizes results across available companies using the median return.
The number of companies represented can change from year to year. These yearly summaries are not official NIFTY or Sensex index returns.
Market breadth
Market breadth is the daily proportion of available stocks whose adjusted closing price rose compared with the previous trading session. This helps show whether gains or declines were widespread across the stocks in the dataset.
Machine-learning forecast
The program uses the 30 company files with the longest histories to test a Ridge regression model. It uses recent returns over 5, 20, and 60 trading sessions, 20-session price volatility, and recent volume change as features. The model estimates the return over the next 20 trading sessions.
Training, validation, and test data are split chronologically so later observations are held out for testing. The model is compared with a simple baseline that predicts zero return.
Project Results
The analysis processed 5,027 usable company files and skipped one file.
- In 2008, the median annual stock-file return was approximately −67.7%; about 6.1% of files had positive returns.
- In 2009, the median annual stock-file return was approximately +89.0%; about 90.4% of files had positive returns.
- On 9,210 test rows, the Ridge model achieved 11.28% MAE and 47.85% direction accuracy.
- The zero-return baseline performed better, with 10.71% MAE and 52.27% direction accuracy.
Based on this test, the Ridge model did not show a reliable predictive advantage over the zero-return baseline.

Limitations
- The dataset ends in June 2020, so 2020 is a partial year.
- The number of company files available varies by year.
- The results summarize the dataset’s available company files and do not represent official NIFTY or Sensex returns.
- The forecast results apply to the tested data and model only; they do not guarantee future performance.
- This project is for educational purposes and is not investment advice.
